# Dra. Cristina Zúñiga Avilés — Oftalmóloga en Apatzingán

Sitio web de una sola página para el consultorio de oftalmología de la
Dra. Cristina Zúñiga Avilés, en Apatzingán, Michoacán.

- `index.html` — el sitio completo, autocontenido (sin dependencias externas).
- Optimizado para móvil y para pacientes adultos mayores.
- Datos estructurados `Physician` para búsqueda local.

Publicado con GitHub Pages.
